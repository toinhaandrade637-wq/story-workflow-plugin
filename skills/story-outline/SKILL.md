# 第二步 · 大纲与分集

## 这一步要交什么（顺序不能颠倒）

| 顺序 | 交什么 | 为什么必须是这个顺序 |
|---:|---|---|
| 1 | **剧情创意 1,500–3,000 字** | 先把故事讲一遍，再谈结构 |
| 2 | 总纲：7–8 段 | 段 = 「局面改变」的次数，不是章数 |
| 3 | 事件阶段表 | 每段里发生了什么、格局怎么变 |
| 4 | 分集／分章细纲 | 每集/章的结果 + 下一集的问题 |

**最重要的一条：第 1 步不许用结构术语。** 不许出现「第一幕」「激励事件」「中点」「B 故事」。
写不出 1,500 字的剧情创意，说明故事还没长出来——**这时候谈结构，就是在给一个不存在的东西贴标签**。

## 什么算过

| # | 判据 | 怎么验 |
|---|---|---|
| 1 | 剧情创意里有一句**能看见的台词或动作** | 通篇都是「他意识到」「他决定」＝没过 |
| 2 | 每段有「目标—阻力—选择—代价」四件 | 缺一件，这段就是过场 |
| 3 | 中段每个单元过 A—B—C—D | 见下 |
| 4 | 核心转折过四道门 | 见下 |
| 5 | 每集钩子是**问题**，不是总结 | 「他能不能救回女儿」✓ /「他决定去救女儿」✗ |
| 6 | 删掉任何一集，季弧光受损 | 删了不影响＝这集是水集 |

## 中段怎么长出来：A—B—C—D

中段塌，是因为把「事件」当「结构」。每一段按四步走：

| 步 | 是什么 | 反例 |
|---|---|---|
| **A** | 主角想要的**具体东西** | 「他想成功」✗（不是东西） |
| **B** | 挡在他面前的**具体障碍** | 「有人反对」✗（太笼统） |
| **C** | 他用了一个**办法**（这一步是发明） | 「他努力了」✗ |
| **D** | 结果：得到/失去，**局面改变** | 「他成长了」✗ |

**关键检验**：把 C 删掉，D 还会原样发生吗？

- 会 → C 是装饰，不是情节
- 不会 → 这段立住了

**C 必须是发明。** 「他去找朋友帮忙」不是发明，「他把自己的病历复印十份贴在对方楼下」是发明。发明的六个来源：处境极端化 / 规则碰撞 / 空间即戏 / 道具机制 / 误会机器 / 反着演。

## 核心转折四道门

一个转折要立住，四道门都要过：

| 门 | 问什么 | 不过的表现 |
|---|---|---|
| ① 意外 | 观众能提前猜到吗？ | 能猜到＝不是转折 |
| ② 可信 | 前面埋过依据吗？ | 没埋＝硬转 |
| ③ 有代价 | 转折让主角失去了什么？ | 没代价＝廉价 |
| ④ 有后果 | 转折之后，故事能不能回到原样？ | 能回去＝这段白写 |

## 分集：多少集合适

**没有公式。** 但有三条实测锚点：

| 锚点 | 数字 | 说明 |
|---|---|---|
| 单场体量 | 中位 **825 字 / 31 行** | 来自 1 部成品 338 场实测（n=1） |
| 单集场数 | 中位 **10 场** | 同上，且集数越多单集场数越少 |
| 一集台词量 | **5,408–9,460 字** | 1.75 倍差，来自字幕实测（n=1） |

**这三条都是 n=1，只能当起点，不能当规律。** 报价的时候说清「这是参照，不是标准」。

分集的实际做法：**先数「不可逆事件」有几个**，一个不可逆事件大致撑 1–2 集。不够，就是集数定多了。

## 尾钩：不是悬念，是承诺

每集末尾留的不是「谜」，是「我下一集会给你什么」。

- 钩子要能被下一集**在开头回应**（不回应，观众觉得被骗）
- 钩子的措辞要能被记住（一句话说得清，不要三段话）
- 系列剧还要多一层：**这一本自己闭合什么 + 给系列留下什么可兑现的位置**

## 常见失败

| 症状 | 病因 | 改法 |
|---|---|---|
| 中段全是过场 | 每段没有「局面改变」 | 按 A—B—C—D 重搭，找不出发明就合并两段 |
| 集数定了但内容不够 | 按「想写多少集」定的，不是按「有几个不可逆事件」 | 重新数事件，砍集数 |
| 每集都在铺，没有结算 | 把「钩子」当成了「悬念」 | 每集必须结清一件事，钩子挂在结清之后 |
| 转折生硬 | 四道门只过了「意外」 | 补门②（前面埋依据）和门③（给代价） |

## 产出之后

写完四件东西，**逐条过「什么算过」那 6 条**。有一条不过就改，不要往下走。

过了就进 `story-script` 写正文。
