## 一、双引擎与骨肉互生核验｜母版表 1

| 核验维度 | 本集具体落点 |
|---|---|
| 密度：前 3 分钟给什么 | 场 11-1（S01-01~S01-22，共 22 镜）：荀未来闯进 502，第一句就是「气死了，真的是快气死了！说那个小屁孩是赵左右，简直就是侮辱我！」；赵了递一杯凉白开「给你败败火啊。」，顺手揭开底牌「我这是在修复通道。」；两个人挤在电脑前修「黑鸽子 v2.1」，修好后的第一句监听，是十六岁赵左右压着嗓子说「你放心，我不会告诉戴主任的。但你要帮我保守这个秘密，好吗？」。三分钟给三件事：两个未来人正式结盟、他们的监听通了、少年有一个他们不知道的秘密 |
| 新鲜度：哪里是观众没见过的 | **用 2008 年的木马病毒监听 2008 年的自己**。不是天眼，不是高科技，是「托人买了两张芯片」，是「熊猫烧香」那几年的土办法；赵了一句「你傻不傻？木马病毒算什么高科技啊。」把科幻拉回现实。第二处新鲜：陈明被嘲「一蹶不振」，坐下打一局，盲狙穿烟爆头，回一句「真不爷们儿。」——他用对方的标准把对方判了。第三处：荀未来一夜之间变成及肩长卷发加络腮胡，原因不是魔法，是少年改了人生 |
| 主心骨（因果死线推进什么） | 主心骨是**一场罗生门**。尚雪举报「他八成是作弊的！」→ 监控显示赵左右考前夜在办公室待了近十分钟 → 赵左右撒谎说在补作业 → 戴娟用「可我办公室只有圆珠笔啊！」拆穿 → 陈明在广播里自曝每晚偷打 CS，只为证明「露出第一题的时候，他就把卷子放回去了。」→ 处分从留校察看降为严重警告，班长撤销，陈明退学。死线推进：疤没有回来，变量却多了一个陈明 |
| 情感填充物（关系怎么动） | ① 徐图图替赵左右删帖、编借口，反被赵左右试探「会不会是戴主任数错了？」；② 赵东来在主任办公室欠起身子「戴老师，你看啊，没教育好孩子呢，是我这个当爸爸的责任」；③ 赵左右被父亲砸门，坐在书桌前翻到《梦的解析》第 058 页，蓝色批注写着「所以梦多总是好事，对吧！」；④ 赵了在雪地长椅上说「嘿！明天，要不要我去学校冒充家长？」，赵左右回头笑「不用了！」 |
| 咬合点：哪一处软肋引爆结构转折 | 软肋是赵左右的**第一名**。他为了保住它撒了第一个谎，再用第二个、第三个谎去圆；真正的转折不是他被抓，是陈明在广播里说「他这次的考试成绩，应该扣除第一题的四分，剩下的分数，全是他自己考的！」——朋友用学籍换他清白。结构转折落在 S09 广播室一段与 S10 走廊耳光 |
| 「不给什么」与「给什么」成对 | 给：水笔与圆珠笔的铁证、陈明每晚在办公室打游戏、荀未来身体被改写。<br>不给：**陈明退学后去了哪**（EP13 才说他回了乡下）；**荀未来的身体为什么变**（只给结果，不给机制）；**戴娟是否真的相信他只看了第一题**（她只处理处分，不给判断）；**赵左右有没有拍卷子**（监控只给进出门，不给室内） |
| 本集判据自查 | 场数 11 与剧本一致；镜号 200 与分镜一致（22+1+11+5+9+24+21+27+32+24+24）；分镜未标单镜时长；没有新规则在最后一幕才发明——黑鸽子 EP03 已建立，本集只是修好它；长卷发是结果，不是新设定 |
