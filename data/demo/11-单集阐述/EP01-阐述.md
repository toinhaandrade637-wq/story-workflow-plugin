# EP01 阐述 · 夺回人生

## 一、双引擎与骨肉互生核验｜母版表 1

| 核验维度 | 本集具体落点 |
|---|---|
| 密度：前 3 分钟给什么 | 场 1-1 至 1-4（S01-01~S04-12，共 29 镜）：一场戏把全剧母题立完——1998 雪夜，6 岁赵左右退回多送的韭菜串（立“守规矩”）、目睹陌生人踹碎雪人（立“世界会毁掉美好的东西”）、蹲地重堆三个雪人并说「三人成众」（立“我只能自己救自己”）。三分钟里没有一句解释性台词，全部用动作 |
| 新鲜度：哪里是观众没见过的 | 不是“穿越回去改命”这个设定新，而是**改命的人用的是 KPI 话术**：场 1-13 主任室里，荀未来用“年级平均分”“升学率考核”这套 2033 年社畜语言降维说服装戴主任，拿到补考资格。观众没见过“用职场话术打 2008 年教导主任”。另一处：场 1-9 卫生室，他准确报出王一漫低血糖，用的是“她手在抖，瞳孔对光慢”——观察方式来自未来，不是来自记忆 |
| 主心骨（因果死线推进什么） | 签 009 号协议 → 回 2008 → 逼 16 岁自己弃理从文。死线：1 年，过期强制召回（1988 伪造身份证到期日 2009.1.20）。本集推进到“他拿到身份、进了学校、建立了接触点”，但**还没有一次成功的改命**——分科表要到 EP02 才被真的改 |
| 情感填充物（关系怎么动） | ① 父子：赵东来买打折蛋糕、带冻土豆回家念亡母——不是温情，是“一个不会表达的男人在用力”；② 朋友：罗爱文的 Suprise 贺卡（英文拼错）、陈明的《答案略集锦》活页本；③ 母子：刘美奕在餐厅那句“你爸就是嘴硬”。三条线都不推进主线，但让「改命」这件事有了具体的疼 |
| 咬合点：哪一处软肋引爆结构转折 | 场 1-35（S35-01~S35-05）餐厅：生日夜门口同时出现两个蛋糕——父亲买的打折蛋糕、匿名放的蓝盒太空蛋糕。赵左右先看见自己家的那个（丑、便宜），再看见门口那个（漂亮、没有署名）。他没问是谁送的，只把两个都拎进屋。<br>**这一处让荀未来第一次意识到**：他以为自己在“救一个会毁掉人生的孩子”，可这个孩子已经有人用穷尽全力的方式在爱。改命从此有了良心成本——EP04 赵父撕书后他才会站在台阶上不知所措，而不是继续执行计划 |
| “不给什么”与“给什么”成对 | 给：三个雪人的来历、009 号协议的三条禁令、荀未来的身份。<br>不给：**赵了是谁**（只在最后一场摘帽露疤，全剧最大悬念）；**荀未来为什么选文科**（只说他抓纸媒回潮，不说舒图）；**2033 年陈明为什么死**（只给墓碑，不给死因）。这三样都是“本集故意不给”，留到 EP03/EP07/EP11 分别揭 |
| 本集判据自查 | 场数 44 与剧本一致；镜号 306 与分镜一致；本集没有出现秒数；没有新规则在最后一幕才发明 |
