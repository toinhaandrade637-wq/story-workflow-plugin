# 小说 · 空白模板

> 缺省体量：60 万字 / 180 章

这套模板只给**骨架**：每一节都写清了「这一节要回答什么」，内容全是空的。
把它整个拷进 `data/projects/<你的标题>/` 就能开工，也可以在里面只挑你需要的段。

## 本形态有 12 段

- `01-立项/立项定位表.md`
- `02-总论/故事圣经.md`
- `03-生活场/生活场与铁律.md`
- `04-人物/人物圣经-c01-角色名.md`
- `05-场景/一景一档-loc01-场景名.md`
- `06-道具/道具总表.md`
- `07-分集/分卷与章纲.md`　← 本目录装的是《分卷与章纲》，不是剧本的集
- `08-细节/伏笔与闲笔.md`
- `09-剧本/第01章.md`
- `11-单集阐述/第01章-细读.md`　← 本目录装的是《章节细读》，不是剧本的集
- `12-项目书/项目书.md`
- `14-终检/终检与复盘.md`

## 本形态不走的段

- `board`：小说没有镜头这一层，分镜表是影视独有的下游。
- `promo`：小说的宣发走出版与平台运营，三阶预告的体例不适用。

> **目录名说明：** 十四段目录是四种形态共用的。`07-分集/` 这一格在小说里
> 装的是《分卷与章纲》；`11-单集阐述/` 里装的是《章节细读》，不是剧本的视听阐述。

## 形态差异体现在哪

| 段 | 本形态与剧集的差别 |
|---|---|
| 立项 | 写总字数 / 卷章 / 平台 / 更新节奏，不写「集数」。 |
| 故事圣经 | 文风七项（视角 / 时态 / 句式 / 用词 / 语气 / 参照 / 忌用）是第一节。 |
| 场景 | 写空间与陈设、同一间屋子在不同章里的气氛变化；不写机位与轴线。 |
| 分卷与章纲 | 按卷走，每卷有独立目标与终点；每章写「推进了什么」。 |
| 章节正文 | 散文体，不是剧本格式；对话用引号，不占独立行。 |
| 章节细读 | 写这一章的视角选择 / 节奏安排 / 删掉的版本；不写镜号、焦段、K 值。 |
| 终检 | 台账按卷分行；复盘四维是开头前三章 / 中段防塌 / 人物立不立得住 / 语言完成度。 |
