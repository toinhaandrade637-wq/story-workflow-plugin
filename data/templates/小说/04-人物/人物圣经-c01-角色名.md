# 人物圣经 · 角色名


## 第一章　角色核心设定与全维档案总卡

> 12 行一次填完。这一章是给导演和演员看的「他是谁」。不写履历，只写能被演出来的东西。

| 字段 | 定稿设定 |
|---|---|
| 角色标准姓名与称谓（全剧唯一；昵称 / 网名一并列出） |  |
| 生理年龄与跨时期状态（各时期岁数与对应年份） |  |
| 出生日期与星座属性（决定故事爆发的锚点日期） |  |
| 所处时空纪元（这个故事里他一共活在几个时间层） |  |

### （二）姿态步态、习惯性微动作与声音台词特质

> 这一节是演员的说明书。走路什么步幅、坐着什么姿势、心虚时手往哪放、被人叫名字时几秒回头、说话什么语速和尾音。

（在这里写）

### （三）各时期从头到脚穿搭拆解

> 这一节就是服化道——造型不是独立部门的事，是「这个人这个阶段的样子」。每个时期一个 #### 编号段，写到能一眼认出是谁。

#### 1. 【某年某季·时期名（EP01–EP08）】：
头：发型 / 帽 / 饰物
上身：内搭（颜色 + 领型 + 是否外翻 —— 这是区分同体角色的硬锁）/ 中层 / 外层
下身：裤 / 裙 + 鞋
随身：包 / 道具 / 手持物
伤效：哪侧、多长、这一期是什么状态

#### 2. 【下一期】……（编号接着排）

| 时期与集数 | 面部与神态 | 全身从头到脚 | 随身道具 |
|---|---|---|---|
|  |  |  |  |

### （五）伤效接戏台账

> 只写「这个人身上会变的伤」，不写道具——道具是第 6 段独立的一份资产，跨人物流转，挂在这里会漏。每处伤一行：哪一侧、哪个部位、多少厘米、第几集产生、分几个阶段变、最后留不留疤。这一节是为了查「上一场腿断了下一场跑得飞快」。

| 伤效 / 体征 | 解剖位置（左右 + 部位 + 厘米） | 产生集场与成因 | 阶段演变（渗血→包扎→结痂→淡化） | 永久留存或消退 |
|---|---|---|---|---|
