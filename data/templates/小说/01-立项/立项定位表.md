# 小说立项表（字数 / 卷章 / 平台 / 读者）


## 一、体量与平台

> 小说没有「集」，只有字数与章。平台决定节奏：连载要每章留钩，出版可以整卷收束。

| 项 | 内容 |
|---|---|
| 形态（小说——写在这一行，下游靠它认形态） |  |
| 总字数（如 60 万字） |  |
| 章数 / 每章字数（如 180 章 × 3300 字） |  |
| 分卷（如 3 卷 × 60 章） |  |
| 平台（起点 / 晋江 / 番茄 / 出版 / 不限定） |  |
| 更新节奏（日更 4000 / 隔日更 / 完结再发） |  |
| 主要读者（如「看男频仙侠的老读者 + 喜欢慢节奏权谋的」） |  |

## 二、一句话故事

> 主角是谁、处在什么境地里、他要什么。小说的一句话可以比影视长一点，但不要超过两行。

| 项 | 内容 |
|---|---|
| 主角是谁（身份 + 处境） |  |
| 他要什么 |  |
| 什么挡着他 |  |
| 读者会跟着他经历什么 |  |

## 三、核心卖点

> 读者在书架上看到封面与简介，凭什么点进来。这一节要能直接写成简介。

| 项 | 内容 |
|---|---|
| 一句话卖点 |  |
| 同类都在写什么 |  |
| 我们不一样的那一条 |  |
| 前 3 章能给出的最强画面 |  |
