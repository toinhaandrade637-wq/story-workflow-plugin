# 短剧 · 空白模板

> 缺省体量：80 集 × 2 分钟

这套模板只给**骨架**：每一节都写清了「这一节要回答什么」，内容全是空的。
把它整个拷进 `data/projects/<你的标题>/` 就能开工，也可以在里面只挑你需要的段。

## 本形态有 13 段

- `01-立项/立项定位表.md`
- `02-总论/短剧设定.md`
- `03-生活场/世界观与规矩.md`
- `04-人物/人物五行总表.md`
- `05-场景/场景档.md`
- `06-道具/道具总表.md`
- `07-分集/全局分集大纲.md`
- `08-细节/伏笔与闲笔.md`
- `09-剧本/EP01-第1集.fountain`
- `10-分镜/EP01-分镜.md`
- `12-项目书/项目书.md`
- `13-预告/预告与宣发.md`
- `14-终检/终检与复盘.md`

## 本形态不走的段

- `analysis`：短剧不写单集阐述——单集只有 1–3 分钟，戏剧功能由分集大纲直接给定，再写一层阐述是重复。

> **目录名说明：** 十四段目录是四种形态共用的。短剧跳过 `analysis` 那一段，
> 其余目录名与剧集一致。

## 形态差异体现在哪

| 段 | 本形态与剧集的差别 |
|---|---|
| 立项 | 体量写竖屏 / 80 集 × 2 分钟 / 前 25 字钩子，不写「季弧光三层」。 |
| 分集大纲 | 每集「一段 350–450 字正文 + 末尾七标签」：开场卡点 / 冲突 / 互动 / 转折 / 爽点 / 期待点 / 结尾钩子。剧集的分集总表没有这七项，也不要求每集一段正文。 |
| 剧本 | 竖屏短剧本：开场 3 秒见冲突，单集 2–5 场，结尾停在未解问题上。 |
