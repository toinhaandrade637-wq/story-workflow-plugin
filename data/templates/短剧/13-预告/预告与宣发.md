## 三、幕后特辑

> 每支解决一个观众可能的疑问，不是「讲制作难点」。先写「观众会问什么」，再写「用什么画面回答」。技术点（化妆/长镜头/灯光）是答案，不是题目。

| 观众可能的疑问 | 用什么画面 / 访谈回答 | 访谈对象 |
|---|---|---|
| 同一个人演 16/41/66 三个年龄，怎么不认错？ |  |  |
| 这是亲情剧还是科幻剧？ |  |  |
| 时间线会不会乱、会不会看不懂？ |  |  |
| 除了穿越，还有没有正常的青春部分？ |  |  |
