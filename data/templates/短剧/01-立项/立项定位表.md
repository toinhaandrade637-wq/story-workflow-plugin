> 这一节是应用侧的商业参数，skill 的七字段里没有，但不用它就算不出「每集几个事件」、也判断不了前 25 字能不能点开。平台与付费点可以待定，集数与时长不能空。

| 项 | 内容 |
|---|---|

## 二、故事设定七字段

> 七字段共享同一组事实，不是七份独立文案。先想清梗概，再回头压一句话——一句话里出现的身份、能力、结局，梗概里必须找得到。

**④ 故事类型要从下面十一类里挑一类**（依据技能包七类题材方法 + 都市爱情钩子图谱）：
神豪＝资源可用后重获主动权｜商战＝拿到或守住具体商业利益｜赘婿＝被低估的家庭成员改变位置｜战神归来＝强者回来守住重要的人｜鉴宝＝被误判的价值被发现并验证｜神医＝解救眼前困境并承担选择｜身份回归＝要不要认领这个身份｜都市爱情＝关系怎么形成或结束｜家庭伦理＝一家人在利益与情感间怎么选｜悬疑复仇＝真相怎么揭开、代价是什么｜逆袭打脸＝被轻视的人怎么拿回尊严。
「都市现实」「非遗传承」「年代情怀」是**题材**，不是类型——写题材，观众不知道点进来会得到什么。

| 字段 | 内容 |
|---|---|
| ① 集数（单个正整数） |  |
| ② 目标受众（类型偏好，不虚构年龄地域统计） |  |
| ③ 核心梗（2–4 个具体机关，用 + 连接） |  |
| ④ 故事类型（十一类里挑一类 + 必要风格） |  |
| ⑤ 一句话故事（60 字以内，不泄底） |  |
| ⑥ 故事梗概（500–600 字，写到明确结局） |  |

## 三、人物小传

> 每位主要人物一个「### 姓名」，下面五行固定顺序：角色类型 / 视觉形象 / 核心标签 / 身份背景 / 成长经历。人数按体量：10 集 3–4 人、30 集 3–6 人、60 集 4–8 人、100 集 5–10 人。只写会持续改变主线的人；只出现一次的功能角色不写小传。
