# 短剧世界观（一句话 / 三条规矩 / 场景清单）


## 一、世界一句话

> 一句话说清「这个地方 + 这条不成文的规矩」。写不出这一句，说明世界观还没立住。

| 项 | 内容 |
|---|---|
| 这个地方是哪里（具体到街区 / 店面 / 单位） |  |
| 这里有什么不成文的规矩 |  |
