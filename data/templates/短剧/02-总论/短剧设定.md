# 短剧设定（核心梗拆解 / 人设反差 / 钩子曲线 / 四阶段因果链）


## 一、核心梗拆解

> 七字段里的核心梗是「一句话」，这里把它拆成能落地的四问。三个梗各一行，写完就能知道第几集该给什么。

| 梗二 |  |  |  |  |

## 四、四阶段因果链

> 每阶段六项都要写。只写「主角做了什么」不叫因果链——对手必须根据上一阶段的结果改策略。

## 五、爽感承诺与优势边界

> 这一节决定「观众为什么点下一集」。五格都要填：
· 主回报只选一个（拿回尊严 / 守住至亲 / 智胜强敌 / 被认可 / 身份自主），副回报可有一个；
· 优势写清「靠什么赢」，边界写清「它不能做什么」；
· 代价写「用错一次会怎样」——没有代价的优势，第一次用就不好看了。

| 项 | 内容 |
|---|---|
| 主回报（观众看完得到什么，只选一个） |  |
| 主角靠什么赢（专业 / 财富 / 人脉 / 身份 / 能力） |  |
| 这个优势不能做什么（边界） |  |
| 用错一次要付什么代价 |  |
| 第一次兑现（第几集、赢了什么具体的东西） |  |

## 六、对手的利益与反制

> 反派的动机不能是「我就是坏」。四格都要填：他要保住什么具体利益、他手上有什么资源、他哪一次判断是对的（对手有效，主角的胜利才值钱）、他失败之后会改成什么策略。
