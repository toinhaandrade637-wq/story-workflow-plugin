# 九编式总论（导演阐述 / 三本时间账 / 花名册 / 逐集子表）


## 一、导演与主创阐述（八维）｜母版第二编

> 前四维是导演/总编剧的创作立场，后四维是四个部门的美学总纲。每一维都要给「这一部戏的具体选择」，能约束下游分镜与置景。写「诗意」「克制」「电影感」等于没写——那是态度，不是参数。

| 维度 | 这一部戏的具体选择 | 它约束下游的什么 |
|---|---|---|
| 1 片名三重解码（表层器物/事件义 → 中层关系博弈义 → 深层人性哲学母题义） |  |  |
| 2 核心哲学母题辩证法（哪两个人性两难对立；怎么外化成终局行动，不许台词背口号） |  |  |
| 3 摄影焦段与运动长镜头哲学（24/35 广角建立 → 50 平视交锋 → 85/100 心理压迫，各用在哪） |  |  |
| 4 悲喜呼吸度与克制表演基调（用轻盈日常消解沉重命运；气口留白放在哪几场） |  |  |
| 5 摄影部门（焦段随心理防线推进；门框 / 柱廊 / 隔断做前景遮挡，外化 C 账信息差） |  |  |
| 6 灯光部门（实用光源物理逻辑；按空间属性与叙事阶段锁白昼 / 夜晚 K 值与光比） |  |  |
| 7 美术与服化道部门（生活包浆怎么做出年代；多人同装时用内搭颜色与领型建立一秒区分硬锁） |  |  |
| 8 声音部门（有叙事功能的同期环境声 + 跨阶段声音桥；高潮哪一刻抽空配乐） |  |  |

## 二、结构 × 情感填充物：四阶段骨肉互生｜母版第四编（一）

> 四阶段不是四幕，是单元阶梯。每个阶段三列都要填：主心骨（因果死线推进什么）、情感填充物（人物关系毛边怎么长）、骨肉互生（哪一处情感软肋直接引爆结构转折）。只填主心骨 = 干；只填情感 = 散。

## 三、A 账：客观顺时序事件链｜母版第四编（二）

> A 账 = 客观真实发生的时间线，不是叙事顺序。按自然时序写，不管观众第几集才知道。每一行都要锁「物理留痕」：车顶冰壳、锁扣刮痕、衣袖印油、伤痕。A 账是查「谁提前到了、谁在撒谎」的唯一依据。

| A 账时间坐标 | 客观发生了什么（按自然时序） | 涉及人物与物理留痕（锁死） | 在 B 账哪几集呈现 |
|---|---|---|---|
| 前史原点（全剧创伤与秘密的源头） |  |  |  |
| 前史传承（核心道具交接 / 同门分岔） |  |  |  |
| 主线首日·案发前序（开场前 1.5 小时至前 5 分钟） |  |  |  |
| 主线首日·实时破局（EP01 当夜窗口） |  |  |  |

## 四、B 账：非线性叙事与钩子｜母版第四编（三）

> B 账管「怎么讲」：冷开场抓不抓人、前史分几阶放、片尾钩子落不落在可视物证上。前史严禁在前三集用大段闪回一次演光——那是把底牌当开场。

| B 账模块 | 本剧怎么设计 | 红线（做不到就是泄气） |
|---|---|---|
| 每集冷开场钩子（前 3 分钟切什么） |  |  |
| 前史信息三阶释放（EP__ 侧面提及 → EP__ 局部推翻 → EP__ 铁证闭环） |  |  |
| 每集片尾强悬念钩子（落在哪个可视物证或不可逆行动上） |  |  |

## 五、C 账：三层认知差漏斗 + 节奏控度｜母版第四编（三）

> C 账是「谁知道什么」的分层，三层缺一层，中段就只剩误会，没有智性快感。第一层：主角+观众知道、局内人不知道 → 看他怎么露馅。第二层：控盘者知道、主角团不知道 → 中后段揭晓时才有震撼。第三层：宏观真相、全体局中人都不知道 → 这是主题那一层。

| 维度 | 本剧怎么设 | 核验标尺 |
|---|---|---|
| C 账第一层（主角+观众 vs 局内隐瞒者） |  |  |
| C 账第二层（控盘者 vs 主角团） |  |  |
| C 账第三层（宏观真相 vs 全体局中人） |  |  |
| 节奏控度·密度（场场过三变测试） |  |  |
| 节奏控度·呼吸度（高压之后给哪个生活气口） |  |  |
| 节奏控度·反转度（每个反转的前序物证在哪） |  |  |
| 节奏控度·克制度（哪几场重场戏忍住不哭） |  |  |

## 六、角色花名册（横向对比）｜母版第五编（一）

> 这不是人物小传的摘要——人物小传回答「他是谁」，这张表回答「这些人摆在一起怎么区分」。表里反差必须成对写：外在保护壳 ↔ 内心真软肋。同场一秒区分硬锁要写到「内搭颜色 + 领型」，不是「穿得不一样」。
