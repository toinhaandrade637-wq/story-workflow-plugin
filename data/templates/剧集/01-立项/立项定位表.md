# 立项定位表（形态与投递 / 一句话 / 作者意图 / 卖点 / 双引擎 / 四维破壁 / 情绪出口 / 质检标尺 / 反套路 / 十维评估）


## 一、形态与投递

> 这一节先定「这东西做多长、投给谁、钩子多长」。形态一改，单集场数、集末钩子规格、分集大纲要不要走，全都跟着变。不确定就写「待定」——但要让下游知道你在等什么，不要空着。如果是 AI 生成形态（AI 真人剧 / AI 动画 / 漫剧），还要额外回答「含人量」那一行。

| 项 | 内容 |
|---|---|
| 形态（长剧 40–45 分钟 / 中剧 15–25 分钟 / 短剧 1–3 分钟 / 电影 / 网络故事片 / AI 真人剧 / AI 动画·漫剧） |  |
| 集数 × 单集时长（如 24 × 45 分钟 / 12 × 22 分钟） |  |
| 目标平台与厂牌（爱奇艺暗流 / 优酷虎鲸 / 腾讯爱燃智议 / 芒果大芒 / 红果 / 抖音 / 不限定）——选平台不是填名字：爱奇艺走 C2C 透明分账 + 厂牌激励，优酷按 EPI 内容价值评估，腾讯按「超级故事四重特质」定级，抖音/红果看前 25 字点击率。选错平台，钩子规格就错了。分账细则见第 12 段 |  |
| 主要受众（平台口径，如「三线以上城市 19–31 岁女性」） |  |
| 单集钩子规格（前 3 分钟立悬念 / 前 25 字定点击 / 集末留问题） |  |
| 含人量（仅 AI 形态必填）：奇观之外，观众凭什么在乎这些人？写一条能落到具体动作上的 |  |

## 二、一句话定位

> 这个人、这个处境、这件事。不要写主题词（「关于成长」这类不算）。

| 项 | 内容 |
|---|---|
| 主角是谁（职业 / 年龄 / 处境） |  |
| 他想要什么 |  |
| 什么挡着他 |  |
| 他会失去什么 |  |

## 三、你要对世界说什么

> 不是「这个故事很感人」，是「这部片在论证一个什么判断」。三问答不出来，说明这个项目还不该做——硬答等于自欺。

| 问 | 你的答案 |
|---|---|
| 命题：这部片在论证一个什么判断？（要能被戏证伪，不能写「关于成长」「关于爱」） |  |
| 私债：这件事跟你有什么关系，为什么非你拍不可？ |  |
| 带走：观众离场时，认知上变了什么？（不是「被感动了」，是「原来___」） |  |

## 四、卖点与辨识度

> 写的是「观众得到什么」，不是「我们多用心」。每个卖点右边要给一句话证明——能落到具体的人、场、反差上；写不出证明的卖点不算卖点。

| 卖点 | 一句话证明（落到人 / 场 / 反差） |
|---|---|
| 一句话辨识度：观众怎么用一句话向朋友介绍这部片？ |  |
| 题材卖点：这个题材里，观众在别处看不到的是什么？ |  |
| 人物卖点：哪个角色是观众会记住、会讨论的？凭什么？ |  |
| 情绪卖点：观众在哪一场会替他紧张 / 替他出口气？ |  |

## 五、首集双引擎

> 高信息密度（前 3 分钟给多少） + 信息新鲜度（多不一样）。

| 引擎 | 具体设计 |
|---|---|
| 高信息密度（前 3 分钟给观众什么） |  |
| 信息新鲜度（哪里是观众没见过的） |  |

## 六、四维认知破壁（前 15 分钟）

> 人设切口 / 情境规则碰撞 / 破局反应 / 高信息密度与单场三变测试，各写一条。第四维不是「视角新不新」，是每场戏结束时必须有一样东西不可逆地变了：生存筹码、C 账知情边界、关系信任度，三者必变其一。只交代信息的场不算。

| 维度 | 设计 |
|---|---|
| 人设切口（前 3 分钟，职业微动作立人） |  |
| 情境规则碰撞（第 8 分钟，死线 × 本土行规同框） |  |
| 破局反应（第 10–15 分钟，先划掉第 1、2 种，再写第 3 种） |  |
| 高信息密度与单场三变测试（每场结束时：筹码 / 知情 / 信任，变了哪一个） |  |

## 七、情绪出口选型

> 母版立项表 3 上半张。三条里选一条主的（可以配一条辅的），写清为什么是这条。选不出来，说明还没想清楚观众靠什么关心这些人。

| 情绪出口 | 选不选 / 主还是辅 | 为什么是这条 |
|---|---|---|
| 一、代际 / 师徒 / 亲缘（刀子嘴豆腐心、报喜不报忧、暗中替晚辈扛雷） |  |  |
| 二、同侪 / 搭档 / 镜像（提防试探 → 背靠背托付，或同源分岔后唤醒） |  |  |
| 三、职业信仰 / 个体尊严（在功利洪流或高压铁笼里守住底线） |  |  |

## 八、剧本质检标尺

> 三道闸口：写得站得住 → 拍得出来 → 播得出去，共十二条。每条都要给「这一集怎么算达标」的可核证据——落到集 / 场 / 镜号才算核过，写「节奏较好」「人物鲜明」等于没写。机器只查标「机」的八条，标「人」的四条必须人读——别指望判据替你验收。

| 闸口 · 标尺 | 这一集怎么算达标（可核证据） | 谁判 |
|---|---|---|
| 一·1 卖点辨识度：观众能一句话说出这剧哪里不一样 |  |  |
| 一·2 戏剧冲突：对抗双方是谁、各自要什么、谁不让步 |  |  |
| 一·3 人物与动机：这个选择为什么只能是他做 |  |  |
| 一·4 对白：去掉人名还认不认得出谁在说 |  |  |
| 一·5 节奏与钩子：前 3 分钟钩子 + 集末必看下一集的问题 |  |  |
| 一·6 故事完整性：因果链哪一环会断、伏笔回收了几条 |  |  |
| 二·7 强场面：每集至少 1 个戏剧 + 视听双高光，能回指镜号 |  |  |
| 二·8 可执行性：场景数 / 群演 / 特殊道具 / 特效在预算内 |  |  |
| 二·9 格式与排版：场头 / 台词 / 场号是否合法可导出 |  |  |
| 二·10 连续性：时间线 / 伤效 / 道具 / 称呼跨集是否一致 |  |  |
| 三·11 合规红线：有没有踩极端对立、拜金、涉政涉黄涉暴 |  |  |
| 三·12 时长与集数：这一集实际可拍时长对不对得上平台规格 |  |  |
