## 一、体量与商业定位

> 电影没有「集」，只有片长。片长与发行路径决定你能拍多大；商业定位决定这片子在哪一类观众里成立。短片写 5–40 分钟，长片写 90 以上——两种体量的节拍密度完全不同。

| 项 | 内容 |
|---|---|
| 形态（电影 / 短片 / 长片——写在这一行，下游靠它认形态） |  |
| 片长（短片 5–40 / 中片 / 长片 90 以上，写具体分钟数） |  |
| 画幅（2.39:1 宽银幕 / 1.85:1 / 1.66:1 / 4:3） |  |
| 发行路径（院线 / 网络电影 / 电影节 / 流媒体；短片只能走电影节或网络短片专区） |  |
| 目标观众（如「25–40 岁，看过犯罪类型片」；不虚构统计数字） |  |
| 预算体量（如「低成本，主场景 3 个，演员 4 人」或「对标同体量某片」） |  |
| 分级倾向（是否有暴力 / 血腥 / 性暗示需要处理） |  |

## 二、一句话与故事梗概

> 一句话是**卖出去的那一句**，梗概是**写给自己看的那一段**。一句话不许泄底（不写「原来 / 真相 / 最终」）；梗概要写到明确结局，把关键解法藏在人物小传里等于没写。

| 项 | 内容 |
|---|---|
| 一句话故事（60 字以内：谁 + 独特处境 + 目标 + 主要阻力） |  |
| 主角是谁（职业 + 处境，一句话） |  |
| 外在目标（他要拿到什么，可验证成败） |  |
| 内在需求（他真正缺什么，自己往往不知道） |  |
| 对抗力量（不只是反派：可以是制度、时间、自己的身体） |  |

## 三、类型 · 调性 · 主题

> 四个词各管一件事，不要混：
· **类型**决定观众带着什么预期进来（犯罪 / 家庭 / 科幻 / 爱情 / 悬疑…）
· **调性**决定片子的温度和节奏（冷硬 / 温情 / 荒诞 / 克制）
· **核心议题**是一个问句（这部片在问什么）
· **主题**是对那个问句的回答，必须是一句判断，不是词
· **母题**是反复出现的那个具体意象或动作（不是抽象概念）

| 项 | 内容 |
|---|---|
| 类型（主类型 + 必要的一个辅助类型） |  |
| 调性（温度 / 节奏 / 幽默感；写具体，不写「高级」） |  |
| 核心议题（一个问句：这部片到底在问什么） |  |
| 主题（一句判断，是对核心议题的回答） |  |
| 母题（反复出现的意象 / 动作 / 声音，要具体到能被拍出来） |  |

## 四、世界规则与核心冲突

> 「世界规则」只写**这一条**：让这个故事非这样发展不可的那条硬规则。它必须能卡住一个具体的人做具体的事（「加装电梯需要 2/3 业主签字」卡住了主角）。**世界观全貌不在这里**——它在第 2 段「总论」，那边写这个世界怎么运转，这边只写这条规则卡住了谁。

| 项 | 内容 |
|---|---|
| 世界规则（这一条：什么规则让这个故事非这样发展不可） |  |
| 这条规则卡住了谁（具体的人 + 具体的行动） |  |
| 违反这条规则的代价（谁付、付什么） |  |
| 核心冲突：谁和谁（或谁和什么）在争 |  |
| 争的是什么（具体到一个东西：一间房 / 一个签字 / 一张纸 / 一条命） |  |
| 为什么现在非争不可（时间压力或事件触发） |  |

## 五、结构四步（启程 / 试炼 / 深渊与灵药 / 归来）

> **这一段是全片的尺子。** 先有的不是三幕，是这四步：
① **启程**——他在日常世界里，带着一个**具体的私心或执念**出发。私心越俗、越具体越好（争遗产、显摆、讨回个说法、想被看见）。
② **试炼**——跨过边界进陌生处境，一路受挫承压。要能数出「他试了几次、每次为什么不成」。
③ **深渊与灵药**——跌到谷底，**最初的执念彻底碎掉**，同时在废墟上拿到与私心**完全相反**的东西（新认知 / 新底牌 / 一段被原谅的关系）。
④ **归来**——带着这份改变回到原来的世界，把结局兑现。

**最容易缺的一环是第③步。** 只有「遇到困难 → 解决了」，没有「执念碎掉」的片子，拍出来就是情景切片，没有后劲。
写的时候只问四句：**他入局图什么？他真掉进深渊了吗？谷底拿到了什么？他带着什么回去了？**

| 四步 | 这一部片的具体内容（写到能被指认的事件 / 场号） | 如果他这一环不在，会变成什么 |
|---|---|---|
| ① 启程：他的私心或执念是什么（越俗越具体越好） |  |  |
| ② 试炼：跨过哪条边界、试了几次、每次为什么不成 |  |  |
| ③ 深渊：哪件事把他的执念打碎了（那一刻他看清了什么） |  |  |
| ④ 灵药：谷底拿到的东西——必须与①**完全相反**（表里对照） |  |  |
| ⑤ 归来：带着这份东西回去后，兑现了什么（内心和解 / 压抑释放 / 认输 / 付了代价） |  |  |

## 六、人物弧光

> 四步说的是故事，弧光说的是人——两者必须对得上：① 启程的私心 = 弧光起点信的那套东西；② 深渊 = 转折；④ 灵药 = 终点。
弧光不是「他成长了」。写清三点，每一点都要能指认到一个事件：
起点（他一开始信什么 / 怕什么）→ 转折（哪件事把这个信念打碎了）→ 终点（他最后做了什么不同的选择）。
主角必须有；对手和关键盟友各一行——对手也要有弧光，否则他只是障碍物。

## 七、幕结构与不可逆选择

> **先回答一句：这部片是哪种结构模型？** 选错模型，后面排什么都会硬。
· **单线三幕**（一人一事、一条抛物线）：绝大多数商业片。走了这条，第 7 段照 15 拍排。
· **双时空 / 回忆闪回**（现在时一人在查，过去时一段往事）：两个时空各一套时间账，75% 处两个时空碰撞。
· **非线性拼图 / 多视角**（同一件事几个人各自说一遍，或时间被打碎重排）：真相藏在最后一块拼图。
· **群像（多主角各自一条弧，同一个枢纽事件交汇）**：没有唯一主角，每人各跑一条小弧光。
· **日常流 / 荒诞**（没有正邪对抗，靠日常器物与季节流转）：没有「拿到灵药」这一步，结尾是余味不是结算。

「不可逆的那一个选择」是全片的轴：做完这个选择，主角再也回不到开场那个状态。

## 八、高光场面与影像风格

> 高光场面 3–5 场就够：那是观众走出影院还会记得的两三个画面。写「是什么场面」，不要写「情绪很满」。
