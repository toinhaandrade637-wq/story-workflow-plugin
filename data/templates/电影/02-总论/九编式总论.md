# 九编式总论（导演阐述 / 三本时间账 / 花名册 / 逐场子表）


## 一、导演与主创阐述（八维）

> 前四维是导演/总编剧的创作立场，后四维是四个部门的美学总纲。每一维都要给「这一部片的具体选择」，能约束下游分镜与置景。写「诗意」「克制」「电影感」等于没写——那是态度，不是参数。

| 维度 | 这一部片的具体选择 | 它约束下游的什么 |
|---|---|---|
| 1 片名三重解码（表层器物/事件义 → 中层关系博弈义 → 深层人性哲学母题义） |  |  |
| 2 核心哲学母题辩证法（哪两个人性两难对立；怎么外化成终局行动，不许台词背口号） |  |  |
| 3 摄影焦段与运动长镜头哲学（24/35 广角建立 → 50 平视交锋 → 85/100 心理压迫，各用在哪） |  |  |
| 4 悲喜呼吸度与克制表演基调（用轻盈日常消解沉重；气口留白放在哪几场） |  |  |
| 5 摄影部门（焦段随心理防线推进；门框 / 窗 / 隔断做前景遮挡，外化信息差） |  |  |
| 6 灯光部门（实用光源物理逻辑；按空间属性锁白昼 / 夜晚 K 值与光比） |  |  |
| 7 美术与服化道部门（主场景的包浆怎么做出；同场多人用内搭颜色与领型建立一秒区分） |  |  |
| 8 声音部门（有叙事功能的同期环境声 + 声音桥；高潮哪一刻抽空配乐） |  |  |

## 二、结构 × 情感填充物：四阶段骨肉互生

> 电影的四阶段不是四幕，是按分钟切的四个单元——第一转折前进第二幕、中点之后、跌到最低点、收束。每个阶段三列都要填：主心骨（因果死线推进什么）、情感填充物（关系毛边怎么长）、骨肉互生（哪一处情感软肋直接引爆结构转折）。只填主心骨 = 干；只填情感 = 散。

| 阶段（分钟区间） | 结构主心骨（因果死线推进） | 情感填充物（关系毛边与温度） | 骨肉互生（软肋怎么引爆转折） |
|---|---|---|---|
| 第一阶段 建局（0–约 15 分钟，到第一转折） |  |  |  |
| 第二阶段 对抗上扬（约 15 分钟–中点） |  |  |  |
| 第三阶段 反噬下坠（中点到第二转折） |  |  |  |
| 第四阶段 解决（第二转折到终场） |  |  |  |

## 三、A 账：客观顺时序事件链

> A 账 = 客观真实发生的时间线，不是叙事顺序。按自然时序写，不管观众第几分钟才知道。每一行都要锁「物理留痕」：车顶冰壳、锁扣刮痕、衣袖印油、伤痕。A 账是查「谁提前到了、谁在撒谎」的唯一依据。

## 四、B 账：非线性叙事与钩子

> B 账管「怎么讲」。电影不是按集留钩，它靠四件事抓人：开场不交代（只给一个动作）、两条线交叉（A 任务 / B 关系）、信息延迟（观众比主角早知道或晚知道）、结尾不解释。每一行写清本片怎么做，以及做不到会怎样。

| B 账模块 | 本片怎么设计 | 红线（做不到就是泄气） |
|---|---|---|
| 开场不交代（前 3 分钟只给动作，不给背景） |  |  |
| 两条线交叉（A 外在任务 × B 内在关系，至少交叉三次） |  |  |
| 信息延迟（哪一条信息压到第几场才给） |  |  |
| 结尾不解释（最后一个镜头给什么，不给什么） |  |  |

## 五、C 账：三层认知差漏斗 + 节奏控度

> C 账是「谁知道什么」的分层，三层缺一层，中段就只剩误会，没有智性快感。第一层：主角+观众知道、局内人不知道。第二层：控盘者知道、主角不知道。第三层：宏观真相、所有人都不知道。

|---|---|---|
| C 账第一层（主角+观众 vs 局内隐瞒者） |  |  |
| C 账第二层（控盘者 vs 主角） |  |  |
| C 账第三层（宏观真相 vs 全体局中人） |  |  |
| 节奏控度·密度（场场过三变测试） |  |  |
| 节奏控度·呼吸度（高压之后给哪个生活气口） |  |  |
