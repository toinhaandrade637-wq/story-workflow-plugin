# 电影 · 空白模板

> 缺省体量：120 分钟

这套模板只给**骨架**：每一节都写清了「这一节要回答什么」，内容全是空的。
把它整个拷进 `data/projects/<你的标题>/` 就能开工，也可以在里面只挑你需要的段。

## 本形态有 14 段

- `01-立项/立项定位表.md`
- `02-总论/九编式总论.md`
- `03-生活场/生活场与铁律.md`
- `04-人物/一人一档-c01-角色名.md`
- `05-场景/一景一档-loc01-场景名.md`
- `06-道具/道具总表.md`
- `07-分集/分幕与节拍.md`　← 本目录装的是《分幕与节拍》，电影没有「集」
- `08-细节/伏笔与闲笔.md`
- `09-剧本/全片剧本.fountain`
- `10-分镜/全片分镜.md`
- `11-单集阐述/重场戏阐述.md`　← 本目录装的是《重场戏阐述》，电影没有「集」
- `12-项目书/项目书.md`
- `13-预告/宣发与预告.md`
- `14-终检/终检与复盘.md`

> **目录名说明：** 十四段目录是四种形态共用的。`07-分集/` 这一格在电影里
> 装的是《分幕与节拍》（15 节拍 + 幕末转折），电影没有「集」；
> `11-单集阐述/` 里装的是《重场戏阐述》，也不是每集一份。

## 形态差异体现在哪

| 段 | 本形态与剧集的差别 |
|---|---|
| 立项 | 写片长 / 画幅 / 发行路径 / 预算，不写「集数 × 单集时长」；第六节先选结构模型（单线三幕 / 双时空 / 非线性 / 群像 / 日常流），再排幕。 |
| 总论 | 四阶段按分钟区间分（不是按集）；逐场子表一行一场；B 账管「开场不交代 / 两条线交叉 / 信息延迟 / 结尾不解释」。 |
| 人物 | 第四章按幕段写传记（第一幕 / 第二幕上 / 第二幕下 / 第三幕），不是逐集编号。 |
| 场景 | 3 列轴线按场次填，不是按集。 |
| 道具 | 流转链按场号写，不是按集。 |
| 分幕与节拍 | 15 节拍 + 两个幕末转折，不是分集总表；每一拍写「进场电荷 → 预期 vs 现实 → 出场电荷」。 |
| 细节 | 跨场伏笔：埋在哪一场、哪几场强化、哪一场收。 |
| 剧本 | 按幕写，40–70 场，第三幕不超过 25%；全片一份 .fountain。 |
| 分镜 | 全片一份；景别配比按画幅定（宽银幕远全 30% / 中景 45% / 近特 25%）。 |
| 场面阐述 | 只写 5–8 场重场戏的视听方案，不是每集一份阐述。 |
| 项目书 | 基本盘八项：片名 / 类型 / 调性 / 片长 / 幕结构 / 场数 / 主场景与演员 / 预算与发行。 |
| 终检 | 台账按幕段分行；复盘四维是开场 3 分钟留存 / 中段防塌 / 骨肉共鸣 / 视听完成度。 |
